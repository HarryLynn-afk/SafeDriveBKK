📷 Add Traffic Images to See Real Detections

This section shows real YOLOv8 detection results with bounding boxes drawn around each detected vehicle. Follow these steps to populate it:

  1. Copy .jpg or .png Bangkok traffic scene images into static/sample_images/
  2. Install the detector: pip install ultralytics
  3. Run the setup script: python scripts/setup_nlp_detection.py
  4. Reload this page — annotated detection results appear automatically

YOLOv8 will detect: motorcycles, cars, trucks, and buses in each image and save annotated copies with bounding boxes to static/detection_results/.
